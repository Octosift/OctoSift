# Roadmap

Ideas for after the first release, roughly in order.

- More sources besides Reddit.
- An MCP server, so assistants can query your leads.
- Run on your Claude Code or Codex subscription. An experimental Codex CLI provider exists
  behind `EXPERIMENTAL_CLI_PROVIDERS=1`; a Claude Code provider (`claude -p --output-format
json`) would work the same way. Headless Claude Code usage is billed to a separate monthly
  credit, not to the plan's usual limits.
